# 稳盈短债C基金产品说明书

## 产品概况

稳盈短债C是一款短期债券型基金，主要投资于剩余期限较短的债券资产，风险等级R2（中低风险）。

## 费率结构

- 申购费率：0%（C类份额不收取申购费）
- 销售服务费：0.40%/年
- 管理费率：0.30%/年
- 托管费率：0.10%/年

## 赎回规则

持有满30天后可随时赎回，赎回资金T+1个工作日到账。
单日单账户累计赎回金额超过10万元时，需提前一个工作日预约。

## 业绩表现

近1年年化收益率约3.10%，业绩比较基准为"中债综合财富指数收益率×80%+活期存款利率×20%"。

## 风险提示

理财非存款，产品有风险，投资须谨慎。基金净值可能波动，投资可能产生亏损。
